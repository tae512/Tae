💻 MATLAB Commands (Summary)

  • taylor(f, x, 'Order', n) : เทย์เลอร์ดีกรีสูงสุด n-1
  • diff(f, x, y) : ดิฟเทียบ x แล้วเทียบ y ($f_{xy}$)
  • gradient(f, [x, y]) : หาเกรเดียนต์เวกเตอร์ $\nabla f$
  • H = hessian(f, [x,y]) / det(H) : เมทริกซ์เฮสเซียนและ Determinant
  • solve(f_x == 0, f_y == 0) : หาจุดวิกฤต (Critical Points)

📐 Key Formulas

• Hessian Discriminant: $D = f_{xx}f_{yy} - (f_{xy})^2$

• Second Derivative Test: $D > 0, f_{xx} < 0 \implies \text{Local Max}$; $D > 0, f_{xx} > 0 \implies \text{Local Min}$; $D < 0 \implies \text{Saddle Point}$

• Chain Rule: $\frac{dz}{dt} = \frac{\partial z}{\partial x}\frac{dx}{dt} + \frac{\partial z}{\partial y}\frac{dy}{dt}$
